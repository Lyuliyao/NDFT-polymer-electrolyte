# Result Summary

Experiment-to-manuscript translation. Every number is from `runs/learn/<experiment>/metrics.json`
(tabulated in `runs/learn/summary.txt`) or from `runs/learn/interpretation/*.json`; the experiment
name is given so the number can be re-read. chi^2 is the force-matching residual per bin in units of
the MD error bar (the block error bars are conservative, so ~0.6 is the noise floor, not 1.0).
"Profile error" is the relative L2 error of the Euler-Lagrange density profile predicted from V(z)
alone against the MD profile, cation / anion. The quoted model is
`joint_v2_L1_C4_R128x128_H64_c001_c002_c004_c006_c008_val3_long` ("V2" below unless stated).

Seeds (added 2026-09-29): the quoted configuration was retrained with initialisation seeds 1 and 2
(data, held-out and validation splits fixed; only the parameter initialisation changes) in
`/mnt/research/MultiscaleML_group/Liyao/salt_in_polymer_eps75/runs/learn/..._val3_long_s{0,1,2}`;
seed 0 there reproduces the quoted model to all printed digits. "3 seeds" below = mean +- sample
standard deviation over seeds 0, 1, 2. The pair closure (V1) is a linear least-squares fit
and has no seed. Gamma is always 2 nbar / S_NN(k_1) (fine grid, Coulomb included, value at k_1, as
`figs/gamma_k1.py` in the research roots, identical to the retired `paper/figures/retired/make_fig3_eps75_only.py`), never the k -> 0 value stored under "structure" in metrics.json.

## Directional Or Weak Findings

- Depth does not help; width does. Depth scan at c = 0.04 (single seed): held-out 0.65 / 0.61 / 0.62 / 0.66 / 0.63 for (L, C) = (1,4) / (2,4) / (2,8) / (3,4) / (3,8), differences within what a seed could do. On the full data set L = 2 worsens the held-out residual (0.727 vs 0.654) and the strongest c = 0.08 well (chi^2 102 vs 38), a 128x128 readout improves both (0.629; 22). Report as an observation with the single-seed caveat.
- Learning curve at c = 0.04 (V3, L = 1): held-out 4.72 / 0.76 / 0.70 / 0.65 for 4 / 8 / 12 / 18 training runs; eight runs reach the noise floor. Supplementary.
- Mode-weighted loss ((k_3/k)^2 on the m = 1, 2 modes of the long-wavelength runs) changes nothing (held-out 0.658 vs 0.654; k_1 values within 0.1-0.6). Supplementary or omit.
- Packing term (V2b, int n_w [-ln(1 - eta)]): indistinguishable inside the range; its volumes get no gradient from c <= 0.06 data. Omit or one sentence in Discussion.
- Early stopping on the test runs is worth 0.03-0.09 in chi^2 (Supplementary table: `_val3` vs test-stopped).
- The highest local densities remain the weak spot: the strongest c = 0.08 well (p01, contrast ~100) is at chi^2 22 with the quoted model as a validation run.

## Open Evidence Gaps

- Seeds: the quoted configuration has three seeds at both eps_r (seed spread of the held-out chi^2 0.003 at eps_r = 7.5, 0.33 at eps_r = 2, the latter from one run, p27). Every other network configuration (depth scan, learning curve, ablations) is single-seed: no significance for network-vs-network differences below ~0.05 there.
- eps_r = 2 data integrity (Methods): two gs21 I/O faults (2026-09-27) dropped stretches of buffered output from running jobs. Checkpoints cut mid-write were discarded (runs resumed from the previous one); in the ion dumps, frames cut mid-line were removed and the rest kept (`tools/dump_repair.py`: 50 dump files in 38 runs at c = 0.04-0.08 affected, 80 frames dropped, 3232 frames missing in total; worst file 1115 of ~2e5 frames, 0.6%; logs `eps2/runs/field_analysis/sip_dfix-repair*`); fix ave/chunk fragments from a job that died within minutes were set aside (`tools/avechunk_repair.py`). The trajectories themselves were not affected; all 138 runs then passed or were flagged by the unchanged acceptance.
- MD Gamma is 2n/S_NN at k_1, not k -> 0; the k_2 shell lies within 15% of k_1 everywhere (Methods sentence).
- The c = 0.12 columns (no field data) are diagnostics only and stay out of the Results text.
